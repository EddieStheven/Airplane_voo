# ETL - AIRPLANE 

Projeto desenvolvido a partir de um desafio proposto pela minha superior, Engenheira de Dados, com o objetivo de aprender na prática como funciona um processo de **ETL (Extract, Transform, Load)**.

A ideia foi trabalhar com uma quantidade grande de dados e passar por diferentes etapas de extração, tratamento e carregamento.

## Task 1

### Objetivo (ETL)

1. Carregar os dados do CSV AIRPLANE 
2. Tratar os dados 
3. Jogar os dados em um banco SQL utilizando Engine e Script SQL 

## Task 2

### Objetivo (ETL)

1. Carregar os dados AIRPLANE do banco e transformar em um DataFrame
2. Tratar os dados, se necessário
3. Jogar os dados em um banco **NoSQL**
